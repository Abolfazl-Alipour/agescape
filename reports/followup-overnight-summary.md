Per explicit instructions, both verified compositional global Benjamini-Hochberg families are presented side-by-side here without selecting one ([431-test CSV](../results/reviewer-phase1-composition-global-bh.csv), [624-test CSV](../results/rev3-composition-global-bh-624.csv)):

| Comparison Metric | `431`-Test Family (`reviewer-phase1-composition-global-bh.csv`) | `624`-Test Family (`rev3-composition-global-bh-624.csv`) |
|---|---|---|
| **Taxa included** | `3` mammalian species (`Human` `291`, `Mouse` `136`, `Naked mole-rat` `4`) | Same `431` mammalian tests + `193` non-mammalian tests (`Fruit fly` `162`: `90` head / `72` body; `C. elegans` `16` whole animal; `Zebrafish` `15` testis) |
| **Total global BH passes (`q < 0.05`)** | **`15 / 431`** (`3.48%`, `min_q = 0.004419`) | **`45 / 624`** (`7.21%`, `min_q = 1.062e-06`) |
| **Passes within existing `431` mammalian tests** | **`15 / 431`** (`Human` `5/291`: Brain `3`, Lung `2`, Kidney `0`; `Mouse` `10/136`: Bladder `1`, Kidney `2`, Muscle `1`, Liver `1`, Lung `2`, Marrow `2`, Spleen `1`; `NMR` `0/4`) | **`17 / 431`** (`Human` `6/291`, `Mouse` `11/136`, `NMR` `0/4`) |

| **Boundary flips on existing mammalian rows** | Baseline (`q_431 >= 0.05` on the 2 borderline rows below) | `2` existing rows drop below `0.05` solely from smaller non-mammal p-values lowering the BH threshold: (1) `Mouse Lung TMS vein endothelial cell` (`q_431 = 0.068955 -> q_624 = 0.039041`, `p = 0.002720`); (2) `Human kidney Kidney_LivingDonor kidney cortex collecting duct epithelial cell` (`q_431 = 0.066741 -> q_624 = 0.037708`, `p = 0.002478`) |

- **Tradeoff when using `431`**: Keeps global FDR calibration strictly bounded within mammalian cell-fraction models (`Human`/`Mouse`/`NMR`), preventing dense insect/nematode significance (`Fruit fly` `26/162` down to `q = 1.06e-06`) from artificially rescuing marginal mammalian slopes (`p ~ 0.0025`). However, it leaves the `193` non-mammal tests in a separate comparison unless adjusted independently.
- **Tradeoff when using `624`**: Controls a single experiment-wide compositional FDR across all `6` species analyzed in the expanded manuscript/revision, at the cost of pooling heterogeneous assays/sample sizes (short-lived whole-animal invertebrates vs human tissue biopsies) such that `2` mammalian rows (`TMS vein endothelial` and `LivingDonor collecting duct`) pass despite identical raw p-values.
